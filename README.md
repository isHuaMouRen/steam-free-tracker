# SteamFreeTracker

![示例](/docs/1.png)

**SteamFreeTracker** 是一款专为玩家打造的免费游戏监控工具。它能够自动检索 Steam 商店中的**限时免费游戏**（即原价售卖、当前折扣为 100% 且结算价格为零的作品）。一旦发现目标，程序将第一时间提醒并引导您一键跳转领取，让您不再错过任何一次官方“喜加一”的福利！

---

## 🚀 快速上手

> [!tip]
> 此软件直接请求Steam商店 (https://store.steampowered.com/) 获得免费游戏索引。请确保你的网络环境足以访问Steam商店！

### 1. 环境准备

在运行本程序前，请确保您的系统已安装 **`.NET Runtime 10`** 或更高版本。本软件依赖此运行时环境。

### 2. 运行与使用

下载并解压后，直接双击运行 **`SteamFreeTracker.exe`** 即可。

#### 💡 运行逻辑说明：

运行后检测到没有免费游戏时就会**退出**，检测到免费游戏在提示完后也会**退出**。因此，此软件**不是**后台监控软件。需要手动运行检测，推荐设置为开机自启，在每次开机时检测
